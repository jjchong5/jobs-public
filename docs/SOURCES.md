# Source Tracker

Master list of every job/event/networking source identified for this project,
pulled from `CLAUDE.md`, `TODO.md`, the original scoping chat
(`docs/initiating chat.txt`), and mentor feedback (`docs/comments_extracted.txt`).
Update this table as sources are tried, blocked, or dropped — don't let status
live only in commit messages or TODO.md prose.

**Fetch method key:** `direct` = HTTP/HTML scrape or public API call from our own
code, `email` = parse alert emails already delivered to an inbox, `bot` = passive
feed from an existing third-party bot, `apify` = managed scraping-as-a-service
(not yet used anywhere in this project — listed as a fallback option for sources
blocked on `direct`).

## Apify subscription plan research (2026-07-04)

Prompted by comparing plans for cost control, not a technical blocker. Findings
for future reference — don't re-derive this from scratch next time spend is
reviewed.

**Public plan lineup** (`apify.com/pricing`): Free ($0, $5 credit) / Starter
($29, $29 credit, Bronze Store discount) / Scale ($199, $199 credit, Silver) /
Business ($999, $999 credit, Gold). All 3 of our actors
(`curious_coder/linkedin-jobs-scraper`, `misceres/indeed-scraper`,
`clearpath/wellfound-api-ppe`) are **pay-per-event**, not rentals — no plan
gates access to them, a paid plan only discounts the per-event price via the
Bronze/Silver/Gold tiers above. Free's $5/mo credit is enough to run them; a
paid plan just buys a cheaper per-1,000-result rate.

**Hidden "Creator" tier** ($1/mo, billed $6/6mo) only appears in the account's
subscription-change wizard (`console.apify.com/billing/subscription?openSubscriptionWizard=1`),
not the public pricing page — tied to promo code `CREATE_YOUR_OWN_LUCK`
(redeemed 2026-03-22, expired 2026-04-23), plausibly a hackathon-sponsorship
perk. **Verified via account tooltip**: Creator's "Universal only" Actor
access means Apify's own 7 generic scraping-framework actors (Web Scraper,
Puppeteer, Playwright, Cheerio, VanillaJS, BeautifulSoup, JSDOM Scrapers) —
**not** the 3rd-party community actors this project depends on. Using it would
mean rebuilding LinkedIn/Indeed/Wellfound scraping logic from scratch on top
of a generic framework, including re-solving Wellfound's DataDome block that
`clearpath/wellfound-api-ppe`'s own proxy pool already handles. Also, the
$500 credit is a **one-time 6-month bonus**, not a recurring monthly credit
like Starter/Scale/Business — worse for steady-state use after month 6.
**Decision: not worth it** — rebuilding scrapers to comparable reliability
costs far more in engineering time than the ~$25-28/mo difference vs. Starter,
and conflicts with this project's explicit non-goal of over-engineering scope
(`CLAUDE.md`).

**Recurring cost estimate** (daily re-poll, `SOURCE_INTERVAL_HOURS=24` for all
3 Apify sources): LinkedIn ~$6/mo (`DEFAULT_MAX_ITEMS=200`/run × 30 days ×
$1/1,000), Indeed ~$0.90/mo (`DEFAULT_MAX_ITEMS=10`/run × 30 × $3/1,000),
Wellfound search unknown/uncapped (`WELLFOUND_SEARCH_PAGE_LIMIT=0`, no
per-run item cap unlike the other two — real incremental-new-item volume
after the initial 784-item backfill is the open unknown, not full re-fetch
volume since duplicate postings dedup). Ballpark total **$10-30/mo** on
Apify; one-time historical backfill cost was ~$4.7 total across all 3.
Claude API tagging cost (Haiku, escalating to Sonnet on low confidence) adds
roughly **$1-5/mo** at current daily incremental-item volume — all-in ballpark
**~$10-35/mo**.

**Decision (2026-07-04, author):** stay on Apify Free tier, top up API
credits as needed, revisit only if monthly spend approaches/exceeds ~$30 or
Wellfound's uncapped daily re-poll cost turns out to be a real driver —
whichever makes switching plans worth it. Not scheduled as a recurring
check; revisit ad hoc when checking Apify billing.
